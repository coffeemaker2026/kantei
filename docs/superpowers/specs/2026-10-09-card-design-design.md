## 1. 目的と前提

### ねらい（運営者が選んだもの）
- **SNS で目を引く**：タイムラインに流れてきたときに目が止まる
- **高ランクを引いた嬉しさ**：ランクの差がひと目でわかり、SR・SSR を引くと嬉しい
- **集める・戦うへの備え**：並べて比べやすく、あとで足す仕組みに使える形にする

「役所の世界観とそろえる」は今回のねらいに入れない。

### 今のカードの課題
- 5ランクとも配置が同じで、細い枠の色しか違わない
- ステータスと伝承文の文字が小さい（スマホで約 10px）

### 基準にする環境：スマホ
利用者の多くはスマホから来る前提で、大きさや動きはスマホを基準に決める。

- ④ではカードが約 340px 幅（実寸の 0.45 倍）で表示される。SNS のタイムラインでは 0.4 倍前後
- カード内の文字は、0.45 倍で表示したときに **11px 以上** になる大きさにする（実寸 24px 以上）
- スマホの写真は縦長が多い。縦長の写真窓（SSR）では、調整欄で切れていた上下が広がって見えるようにする
- 演出は位置・回転・透明度の変化だけで作り、重い処理を足さない

### 守る方針（CLAUDE.md より）
- サイトの動作中に AI もサーバーも使わない。カードはブラウザ内の Canvas で描く
- 写真は外に送らない・保存しない
- 既存の特定のカード（カードダスなど）に寄せない、オリジナルのデザインにする

## 2. 決まったこと

| 項目 | 決定 |
|---|---|
| 大きな方向 | ランクで型（格）が変わる。SSR の型は写真をカード全面に広げる |
| 型の数 | 4種類：Z／N・R／SR／SSR |
| 共通の位置 | 名前は上、情報欄（属性・ステータス・伝承文・番号）は4種類とも同じ位置 |
| 集める・戦うへの備え | 属性を図形の紋で出す。写真がなくても描ける形にしておく（使うのは後） |
| 合計の強さの数値 | 出さない（戦う仕組みの決まりが固まってから考える） |
| ④の演出 | SR・SSR はめくる前後に光を足す。Z はめくったあとしおれる |
| 作り方 | `card.js` を `frontend/src/js/card/` に分け、型ごとの部分と共通の部分を分ける |

画面見本は `.superpowers/brainstorm/` の `four-types.html`（型）と `attr-emblem.html`（紋）にある（Git・配信の対象外）。

## 4. カードの割り付け

座標はすべてカードの実寸（750×1050px）。

### 4.1 型ごとに違うところ

| | Z | N・R | SR | SSR |
|---|---|---|---|---|
| 地 | 再生紙（生成りの地に細い横すじ） | 紺 `#16203A` | 紺 `#16203A` | 写真（全面） |
| 枠 | 点線の枠、写真の上にセロハンテープ | 25px の枠。N は銅、R は銀のグラデーション | 25px の金のグラデーション。写真窓の上の角に金の飾り | 25px の虹色のグラデーション。粒の光 |
| 写真窓 | x100〜650・y185〜625（550×440）。写真は白黒寄り | x56〜694・y184〜624（638×440、今と同じ） | x25〜725・y170〜650（700×480）。上下に金の線、後光の筋 | 枠の内側全部（700×1000）。下 62% を暗くするグラデーションを重ね、文字を読めるようにする |
| 名前の色 | 墨色 `#3E3A33` | 生成り `#F1EAD8` | 金 `#F3DC8C`、金色のにじみ | 白、金色のにじみと影 |
| ランクの判子（右上） | 灰色の線だけ、かすれ | 朱の丸 | 金の丸、濃い茶の文字 | 虹色の丸、ほかより大きい（直径 150px） |
| 情報欄の地・棒の色 | 薄い墨・灰色の棒 | 薄い白・銀（N は銅）の棒 | 薄い金と金の細枠・金の棒 | 薄い白・虹色の棒 |

### 4.2 4種類で共通のところ

| 要素 | 位置・大きさ |
|---|---|
| 名前 | 左上。x60、文字の下端 y110。Zen Antique、最大 58px、幅 480px に収まらなければ 32px まで縮める |
| （※元の名前） | x62、文字の下端 y150。26px |
| 情報欄 | x45〜705・y655〜1025 |

## 5. 写真の調整と型ごとの写真窓

写真の調整（位置・大きさ・切り抜き）は②で行い、そのときはまだランクが決まっていない。そこで次のようにする。

- 調整欄は今の **638×440 の枠（基準の枠）** のまま変えない。`editor.js` の `PW`・`PH`・`imgRect`・切り抜きの座標の持ち方も変えない
- 各型の写真窓では、基準の枠を窓の中央に置き、基準の枠に描くのと同じ位置・倍率で写真を描く。窓が基準の枠より大きい型では、写真の基準の枠からはみ出した部分も見える
  - 窓が基準の枠より小さい型（Z）では、基準の枠を窓に収まるよう縮める（550/638 倍）
  - 窓が大きい型（SR・SSR）は、等倍のまま周りを広げる
- 写真がない部分は神界の背景（暗い紺のグラデーション＋後光の筋）で埋める。Z は灰色寄りの背景にする
- 切り抜きありのときは、もともと背景が神界なので、窓が大きくても自然につながる。後光・ふちの光は今と同じ
- 切り抜きなしのときのスポットライト（周囲を暗くする効果）は、窓の大きさに合わせてかける
- 光の色（ランク別）と、Z を白黒寄りにすることは今と同じ

利用者から見ると「調整した構図が真ん中にあり、高ランクほど周りまで広がって見える」。

## 6. 属性の紋と写真なしの描き方

### 6.1 属性の紋
9つの属性に図形の紋を付ける。色の付いた丸（白い細い縁）の中に白い図形を描く。Canvas の Path2D で描く。

| 属性 | 図形 | 丸の色 |
|---|---|---|
| 雷 | 稲妻 | `#C9A227` |
| 炎 | 炎 | `#C8462E` |
| 水 | しずく | `#2F6FB0` |
| 風 | 渦を巻く3本の線 | `#3E9A7A` |
| 土 | 山 | `#8A6440` |
| 闇 | 三日月 | `#4B3A78` |
| 光 | 日（中心の丸と8本の光） | `#E8C860`（図形は濃い茶 `#3A2A08`） |
| 無 | 輪 | `#7A808E` |
| 生活 | 湯気の立つ湯のみ | `#A89A84` |

図形は見本 `attr-emblem.html` の SVG（44×44）を元にする。Z の属性は判定でいつも「生活」になる。

### 6.2 写真なしの描き方
`drawCard(card, { photo: null })` のとき、写真窓を神界の背景で埋め、中央にその属性の紋を大きく（窓の高さの半分ほど）薄く（不透明度 0.25 前後）描く。今回は画面から使わない。挑戦状などで使うときに、種類ごとの絵柄に差し替えられるよう、写真窓の部分（`window.js`）だけで完結させる。

## 7. ④のめくる演出

今の流れ（裏面 → 0.9 秒で表にめくれる）に、ランクで次の動きを足す。動きは CSS の transform・opacity・filter（drop-shadow）だけで作る。

| ランク | めくる前 | めくった直後 | 足す時間 |
|---|---|---|---|
| SSR | 裏面が約 0.4 秒小刻みに震え、ふちが虹色に光る | カードの後ろから虹色の光がはじける（約 0.6 秒で消える） | 約 1 秒 |
| SR | 同じ動きで、光は金色 | 金色の光がはじける | 約 1 秒 |
| R・N | なし | なし | 0 |
| Z | なし | 約 0.5 秒かけて少し傾き（-3 度前後）、少し沈む。次にめくるまでそのまま | 約 0.5 秒 |

- 動きを減らす設定（`prefers-reduced-motion: reduce`）の人には、どれも出さない（今のめくる動きと同じ扱い）
- 再審でもう一度めくるとき、「別の持ち物を鑑定する」で戻るときは、前の演出の状態（Z の傾きなど）を消してから始める
- 演出のあいだもボタンは押せる。演出の途中で再審を押したときは、演出を止めて次のめくりに移る

## 8. 作り

### 8.1 ファイルの分担（`frontend/src/js/card/`）

| ファイル | 役割 |
|---|---|
| `index.js` | `drawCard(card, photoState)`・`ensureFonts()` を出す。ランクから型を選び、枠 → 写真窓 → 型の小物 → 名前・判子 → 情報欄の順に描く |
| `layouts.js` | 4つの型。型ごとに「写真窓の位置」「色の一式」「地と枠を描く」「小物を描く（テープ・角飾り・粒の光など）」「判子を描く」を持つ。ランク → 型の対応表もここ |
| `info.js` | 共通の情報欄。位置は1か所で決め、型からは色の一式だけを受け取る |
| `emblems.js` | 属性ごとの紋（Path2D と色）と、紋を描く関数 |
| `window.js` | 写真窓。今の `renderWindow` を、窓の大きさが変わっても描けるようにしたもの（5章）と、写真なしの描き方（6.2） |
| `draw-util.js` | 角丸の形、文字の自動縮小、折り返し（今の `rr`・`fitFont`・`wrap`） |

- `main.js` は `./card/index.js` から読み込むように変えるだけ。`drawCard` の引数と戻り値（750×1050 の Canvas）は変えない
- ①の見本のカード3枚も同じ `drawCard` で描くので、新しい型で出る
- 今の `card.js` は消す（中身は Git の履歴にある）

### 8.2 ④の演出
- `main.js` の `showCard()` で、ランクに応じた演出用のクラス（例：`fx-ssr`・`fx-sr`・`fx-z`）を `.stage` に付け外しする
- 動きは `kantei.css` に書く。動きを減らす設定では `@media (prefers-reduced-motion: reduce)` で止める

## 9. 確認テスト

### Vitest（`frontend/src/js/card/*.test.js`）
Canvas を使わない部分を確かめる。
- 5ランクすべてに型があり、N と R は同じ型を使う
- 4つの型で、情報欄の位置（表 4.2）がすべて同じ
- `appraise.js` の9つの属性すべてに紋がある
- 文字の自動縮小：長い伝承文では大きさが下がり、24px より小さくならない（`measureText` は文字数で幅を返す仮のもので確かめる）
- 写真窓の置き方：基準の枠が各型の窓の中央に来て、Z では縮み、SR・SSR では等倍になる

`appraise.test.js` と `appraise.golden.json` は変えずにそのまま通る。

### Playwright（`tests/`）
スマホ幅とパソコン幅の両方で動かす（今の設定どおり）。
- 写真は見本の写真を使う。見本の写真の署名と `appraise.js` から、Z・N・R・SR・SSR になる品名・分類をテストの準備で探し、その入力で④まで進め、カードの画像が出て、ランクに合った演出用のクラスが付くことを確かめる
- 動きを減らす設定では、演出用のクラスの動きが出ないことを確かめる
- 5種類のカード画像をテスト結果に添付し、目で確かめられるようにする（画素の一致までは見ない。書体の読み込みで揺れるため）
- 既存の画面テスト（`flow.spec.js` など）がそのまま通る
